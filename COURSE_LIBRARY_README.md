# Course Library 1.0.0

The app loads course files from `data/courses/manifest.json`.

## Structure

- `data/courses/FI/*.json` — one course configuration per file
- `data/courses/manifest.json` — list of course files loaded by the app
- `data/courses_2026-08-07.json` — combined fallback file

## Porvoo Golf 2026

Porvoo Golf is marked provisional. The club opened new holes 4–7 in July 2026 and published their approximate official lengths. The club also states that new Slope and Course Rating values will be published later. Therefore CR/Slope are intentionally left blank until official values are available.
